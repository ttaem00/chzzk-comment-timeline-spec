CVA-TTAEMPAD / COMMENT GUIDE

한계와 문제 해결

모호한 입력은 원문을 남기고, 정상 시각은 가능한 한 보존합니다. 다만 원문 보존을 모든 표현의 자동 이해와 혼동하지 않습니다.

확인 안내가 보일 때

상황읽는 방식확인할 일
01:23 시작 (02:55)앞 시각 보존, 괄호 시각 안내두 순간인지 범위인지 확인
12:99 오류 뒤 정상 행오류 행 원문·진단, 정상 이웃 보존초가 00–59인지 확인
지나치게 큰 수·소수·잘못된 자리수 시각해당 잘못된 시각을 확정하지 않음주 항목을 정수 MM:SS 또는 H:MM:SS로 작성
깊이를 건너뛴 제목부모 누락 진단위 단계 제목 확인
끝 없는 하이라이트기존 원문·시각 보존, 범위 보장 없음명시 종료 또는 순간 역할 사용
부분 댓글끝 미확정 가능완전한 본문인지 확인
같은 시각·역순 시각별개 항목 보존원문 설명과 순서를 확인
모르는 태그·일반 안내원문 또는 진단지원 형태 표와 대조

한 행의 오류 때문에 나머지 정상 이동 지점을 없애지 않습니다. 원문이 시간축 항목으로 읽히지 않았다면 미리보기의 원문·진단을 확인하세요.

보장하지 않는 것

  • 자유문장 어디에든 들어 있는 숫자를 무차별로 시각으로 바꾸지 않습니다.
  • 날짜·URL·댓글 ID를 시각으로 해석하지 않습니다.
  • 괄호 시각을 자동 이동 지점·끝 시각·정정 시각으로 확정하지 않습니다.
  • 전각 숫자, 임의 분류 제목, 복잡한 Markdown·HTML의 모든 변형을 지원하지 않습니다.
  • 들여쓰기의 모양만으로 참여 사실·장면 의미·여섯 단계 구간을 만들지 않습니다.
  • 이름이 같다는 이유로 채널 신원·전 구간 참여·실제 사건 싱크를 확정하지 않습니다.
  • 자동 댓글 게시, 답글 전체 자동 수집, 기존 채택본 자동 변경을 수행하지 않습니다.

짧고 명확하게 작성하는 방법

  1. 시각은 줄 앞에 쓰고 설명을 붙입니다.
  2. 여러 순간은 /, 범위는 ~와 역할을 사용합니다.
  3. 주제는 #, 하위 주제는 ##로 명시하면 추론을 줄일 수 있습니다.
  4. 별도 색인은 단독 ■ 또는 구분선 뒤에 둡니다.
  5. 가져온 뒤 미리보기의 원문·시각·구조·안내를 확인합니다.

지원하지 않는 사례를 제보할 때는 개인정보를 제거한 최소 예제, 기대 결과, 실제 결과를 함께 적어 주세요. 기여 안내를 참고할 수 있습니다.
