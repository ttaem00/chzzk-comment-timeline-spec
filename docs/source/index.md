# 댓글에서 장면까지

다시보기 댓글에 적힌 시각을 **읽고, 확인하고, 시간축에 담는 방법**을 안내합니다. 기존 댓글은 그대로 가져올 수 있고, 새 댓글은 간단한 시각 목록으로 시작할 수 있습니다.

```text
00:00 방송 시작
02:35 오늘 할 게임 이야기
08:12 다시 보고 싶은 순간
```

**한 줄은 하나의 이동 지점**입니다. `02:35`는 영상이 시작한 뒤 2분 35초입니다. 방송 날짜나 실제 시계의 시각이 아닙니다.

## 가장 짧은 사용 순서

1. 작업실에서 시간표 댓글을 선택하거나 평문·지원 파일을 가져옵니다.
2. 미리보기에서 시각, 주제·장면·순간, 원문과 확인 안내를 살펴봅니다.
3. 확인한 자료를 **시간축에 불러오기**로 채택합니다.

파일 선택이나 미리보기만으로 기존 자료를 덮어쓰지 않습니다. 이미 채택한 자료는 새 해석기가 나왔다고 자동으로 바뀌지 않습니다.

## 무엇부터 읽을까요?

- **처음 작성한다면:** [지원 형태 한눈에](formats.md)에서 짧은 예제를 골라 쓰세요.
- **이미 작성된 댓글이라면:** [기존 댓글 읽기](existing.md)에서 들여쓰기·목차·분리된 목록을 확인하세요.
- **시작과 끝을 지정한다면:** [구간과 강조](ranges.md)에서 순간과 범위를 구별하세요.
- **다른 시점을 찾는다면:** [인물과 합방](people.md)에서 이름 단서와 확인된 참여를 구별하세요.

## 이 안내의 범위

공개 편집 초안 **0.4**, 소비자 **CVA-탬패드 0.3.23 후보**, 출력 식별자 `comment_preview.v2`를 기준으로 설명합니다. 이 사이트는 읽기용 문서입니다. 댓글을 입력해 해석하는 온라인 서비스나 제품 소스 배포가 아닙니다.

지원하는 입력은 [지원 형태](formats.md), 불명확한 입력은 [한계와 문제 해결](limits.md)에 따로 정리했습니다. 모든 자연어 댓글을 자동으로 이해한다고 약속하지 않습니다. 예제의 인물·곡·장면은 합성 자료입니다.
