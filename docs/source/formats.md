# 지원 형태 한눈에

같은 시각도 **순간**, **이야기 구간**, **관련 인물 단서**로 쓰일 수 있습니다. 아래 표는 현재 읽는 형태와 그 의미를 함께 보여 줍니다.


D1·D2·Dn, Point, 예상 구간이 낯설다면 [시간축 읽는 법](timeline.md)을 먼저 보세요. 아래의 지원 표와 연결된 문서에는 댓글 원문과 시간축 결과 그림이 함께 있습니다.

## 시각과 기본 목록

| 형태 | 짧은 예제 | 읽는 의미 |
|---|---|---|
| 앞에 시각 | `02:35 첫 장면` | 하나의 순간 |
| 뒤에 시각 | `첫 장면 [02:35]` 또는 `첫 장면 - 02:35` | 하나의 순간 |
| 시각만 | `54:30` | 제목 없는 책갈피 |
| 강조된 시각 | `**02:35** 첫 장면`, `__02:35__ 첫 장면` | 강조 기호를 벗겨 시각을 읽고 원문 보존 |
| 글머리표 | `- 02:35 장면`, `▶ 02:35 장면`, `• 02:35 장면` | 문맥에 따라 순간 또는 목차 항목 |
| 복수 시각 | `13:20 / 15:10 같은 장면` | 서로 다른 두 이동 지점 |
| 각 시각의 설명 | `01:00 첫 장면 / 02:00 두 번째 장면` | 각 시각과 각 설명 |
| 반복 시각 | `01:00 첫 설명` 다음 `01:00 다른 설명` | 별개의 원문 항목 두 개 |

시각은 `MM:SS` 또는 `H:MM:SS`입니다. 초는 두 자리 00–59이고, 세 부분 형식의 분도 00–59입니다. `60:00`은 1시간입니다. 주 항목에는 정수 초를 사용합니다.

**슬래시는 여러 순간, 물결표·대시는 범위**입니다. `13:20 / 15:10`을 13:20부터 15:10까지 재생하는 구간으로 바꾸지 않습니다. 괄호 안 시각은 별도 규칙이므로 [괄호 시각](existing.md#괄호-속-시각은-확인해-주세요)을 확인하세요.

## 목차와 구조

| 형태 | 짧은 예제 | 읽는 의미 |
|---|---|---|
| 명시 제목 | `# 01:00 게임`, `## 02:00 첫 판` | 주제·하위 구간, 깊이 1–6 |
| 자연 목차 | `01:00 게임` 다음 `- 02:00 첫 판`, `--02:10 사건` | 주제 D1 → 장면 D2 → 순간 |
| 분류 제목 | `💬 저챗` 다음 `01:00 등장` | 다음 실제 시각을 시작으로 쓰는 주제 |
| 트리 표기 | `└ 02:10 사건`, `ㄴ 02:10 사건` | 구조 안의 순간 |
| 명확한 들여쓰기 | `01:00 게임` 다음 `  02:00 첫 판` | 상대적인 안쪽 행을 하위 장면으로 추론 |
| 독립 목록 구분 | 단독 `■` 또는 `---` 뒤의 새 시각 목록 | 앞 목록의 부모를 이어받지 않는 별도 목록 |

**평평한 목록은 순간으로 유지**합니다. 빈줄이나 일반 문장만으로 주제·종료 시각을 만들지 않습니다. 자연 목차는 추론이라는 표시와 원문을 함께 확인할 수 있습니다. [상세 예제](existing.md)를 참고하세요.

## 구간, 강조, 보조 정보

| 형태 | 예제 | 의미·주의 |
|---|---|---|
| 명시 범위 | `- 02:00 ~ 03:00 [메모] 설명` | 시작 포함·끝 제외 구간 |
| 순간 역할 | `[P]`, `[포인트]` | 하나의 순간 |
| 메모·먼저 볼 곳 | `[M]` / `[메모]`, `[W]` / `[볼 곳]` / `[먼저 보기]` | 순간 또는 명시 범위 |
| 하이라이트 | `[H]` / `[하이라이트]` | 끝이 있는 범위 |
| 예상 후보 | `[H?]` / `[예상]` | 끝이 있는 검토 전 후보 |
| 합방 범위 | `[합방]` | 끝이 있는 합방 맥락 |
| 작성자 강조 | `⭐`, `★`, 독립된 `BEST` | 작성자의 강조, 점수·승인 아님 |
| 부가 설명 | `설명:`, `맥락:`, `검토 상태:` | 직전 항목에 붙는 텍스트 |
| 떨어진 원본 구간 | `원본 구간: 02:00 ~ 03:00; 06:00 ~ 08:00` | 지정한 원본 부분만 보존 |
| 명시 참여자 | `합방: 가상A, 가상B` | 직전 제목·합방 범위의 명단 |
| 관련 인물 | `(w. 가상A)`, `(w/ 가상A, 가상B)`, `(with 역할A(가상A))` | 검색 후보, 참여·싱크 확인 아님 |
| 원문별 별칭 | `별칭: 역할A = 가상A` | 같은 원문 안에서만 적용 |

범위가 필요한 역할에 끝이 없으면 권고 문법으로 확정하지 않습니다. 기존 댓글의 호환 경로는 원문 라벨과 시각을 보존하며 확인을 안내할 수 있습니다. [구간과 강조](ranges.md), [인물과 합방](people.md)에서 경계를 설명합니다.

## 문서와 파일

선택한 원글·답글, 평문 TXT, `chzzk.comment-timeline` v1 JSON을 읽습니다. 참가자 한 줄 입력·참가자 JSON·기존 합방 자료는 시간축 댓글과 목적이 다른 입력입니다. [파일 가져오기](files.md)를 참고하세요.
