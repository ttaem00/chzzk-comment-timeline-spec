요약과 JSON 가져오기

호환 시간축 JSON은 ttaem.com에 게시하지 않고 로컬 파일로 가져올 수 있습니다. CVA 등 분석 도구에서 정리한 큰 흐름·장면·순간·검토 범위를 지원 형식으로 준비하면, 탬패드에서 미리보기한 뒤 같은 시간축에 담을 수 있습니다.

다만 CVA 공개 요약의 원본 editor-tools.json과 로컬에서 여는 호환 시간축 JSON은 형식과 적용 경로가 다릅니다. 아래는 CVA-탬패드 0.3.23 기준 안내입니다.

어떤 자료를 가져오나요?

자료어떻게 사용하나요?ttaem.com 게시가 필요한가요?
CVA 공개 요약 · viewer_editor_tools.v1현재 다시보기의 공개 editor-tools.json을 자동으로 불러옴현재 자동 연결은 해당 영상의 공개 자료가 있어야 함
호환 시간축 JSON · chzzk.comment-timeline, version: 1로컬 파일 열기 → 미리보기 → 확인 후 시간축에 불러오기필요 없음
시간표 TXT댓글이나 직접 정리한 시각 목록을 파일로 열어 확인 후 적용필요 없음
저장한 컷 작업 JSON‘작업 이어 열기’로 이전 편집 작업을 복원필요 없음

파일 확장자가 모두 .json이어도 용도가 같지는 않습니다. 요약 파일을 컷 작업으로 열거나, 컷 작업을 댓글 시간표로 넣지 마세요. 참가자·합방 자료는 별도 파일 안내를 따릅니다.

ttaem.com의 공개 요약을 사용하려면

  1. 공개 요약 목록에서 방송과 다시보기를 확인합니다.
  2. 해당 다시보기를 열고 탬패드 작업실에 들어갑니다.
  3. 공개 요약이 있으면 장면 목록과 요약 시간축에서 확인합니다. 댓글 자료와는 출처를 구분해 읽으세요.

공개 요약 페이지는 /vods/영상번호/report, 앱이 요청하는 자료는 /vods/영상번호/editor-tools.json입니다. 현재 다시보기의 영상 번호와 자료의 영상 번호가 같아야 합니다. 요약이 없는 영상도 댓글이나 로컬 호환 시간표로 작업할 수 있습니다.

현재 ‘시간표 파일 열기’는 CVA 공개 요약의 원본 editor-tools.json을 그대로 가져오는 입력이 아닙니다. 다른 사이트의 JSON 주소를 넣으면 자동으로 연결되거나, 파일 이름만 바꾸면 호환되는 기능도 제공하지 않습니다.

게시 없이 로컬 JSON으로 사용하려면

  1. 자료를 chzzk.comment-timeline 버전 1의 .json 파일로 준비합니다. 댓글 평문이 있으면 .txt를 사용할 수도 있습니다.
  2. 작업실의 댓글 가져오기 → 시간표 파일 열기에서 파일을 고릅니다.
  3. 미리보기에서 영상 시각·항목 종류·부모 구간·원문 또는 생성된 시간표·확인 안내를 살펴봅니다.
  4. 사용할 자료를 시간축에 불러오기로 적용합니다. 파일 선택과 미리보기만으로 기존 자료를 덮어쓰지 않습니다.

이 파일을 ttaem.com이나 댓글 게시판에 먼저 올릴 필요는 없습니다. JSON 파일 전체를 댓글 입력칸에 붙여 넣는 방식도 필요하지 않습니다. 로컬 가져오기는 파일의 시간표를 읽는 기능이며, 영상 파일 자체를 포함하거나 방송 요약 페이지를 새로 게시하지 않습니다.

CVA에서 정리한 내용을 호환 형식으로 옮길 때

공개 요약을 만드는 도구가 호환 시간축 JSON을 따로 내보내거나, 작성자가 아래 형식에 맞춰 자료를 준비해야 합니다. 이 문서는 현재 앱에 자동 변환 버튼이 있다고 안내하지 않습니다.

옮길 내용호환 항목확인할 것
큰 흐름 D1role: "chapter", depth: 1시작·끝이 확인된 큰 구간
그 안의 장면 D2role: "chapter", depth: 2바로 위 D1과 구간 관계가 맞는지
이동할 한 순간 Pointrole: "point" 또는 role 생략startSec만 사용하며 끝을 임의로 붙이지 않음
검토 전 예상 구간문서 raw 안의 [H?] 또는 [예상] 범위확인한 시작·끝. 0.3.23은 entries의 expected_highlight 직접 입력을 거부하므로 원문 표기로 준비
작성자가 지정한 하이라이트role: "highlight"끝이 있는 제안 범위이며 실제 컷 선택은 별도

시각은 영상 시작부터 지난 정수 초입니다. 확인되지 않은 종료를 만들어 넣지 마세요. 이 형식은 장면 시간표를 전달하며, 공개 요약의 자막·채팅량·시청자 클립·모든 근거 자료를 통째로 복원하는 형식은 아닙니다. 항목의 원문 출처가 있으면 raw로 보존할 수 있고, entries로 만든 시간표는 원본 댓글이라고 표시하지 않습니다. 세부 필드와 제한은 파일 형식과 예제를 참고하세요.

열어 볼 수 있는 JSON 예제

아래는 10분짜리 가상 영상의 장면 시간표입니다. 실제 방송 분석 결과가 아니며 특정 다시보기에 자동으로 연결되지 않습니다. JSON 예제 열기에서 파일을 확인하고 .json으로 저장할 수 있습니다.

JSON
{
  "format": "chzzk.comment-timeline",
  "version": 1,
  "documents": [{
    "name": "가상 영상 요약 시간표",
    "raw": "# 00:00 ~ 10:00 첫 게임\n## 01:00 ~ 05:00 첫 판\n- 02:35 다시 볼 순간\n- 03:00 ~ 03:20 [H?] 검토할 장면"
  }]
}

예제의 D1은 00:00–10:00, D2는 01:00–05:00, Point는 02:35, 예상 구간은 03:00–03:20입니다. 숫자와 역할의 뜻은 별도 목차인 시간축 용어에서 확인하세요.

이 예제는 raw로 시간표 표기를 담아 [H?]의 후보 의미를 보존합니다. JSON 문자열의 \n은 줄바꿈입니다. 직접 항목 객체를 만드는 entries 예제와 필드 설명은 파일 형식과 예제에서 확인하세요.

루트 videoNo는 선택사항입니다. 특정 다시보기용으로 지정했다면 현재 열린 영상 번호와 같아야 하며, 다르면 가져오기를 거부합니다. 이 예제에는 가상 영상 번호를 넣지 않았으므로 실제 작업에 사용하기 전 내용과 영상 길이를 확인하세요.

막힐 때 확인할 것

  • 지원 형식 오류: 파일 안의 format, version, documents를 확인합니다. viewer_editor_tools.v1 요약 원본은 로컬 시간표 입력과 다릅니다.
  • 영상이 다르다는 안내: 루트 videoNo와 현재 다시보기를 확인합니다. 오류를 없애려고 다른 영상의 시간을 그대로 적용하지 마세요.
  • 시각·부모·종료 안내: 같은 영상의 실제 시각인지, D2의 D1 부모가 있는지, 시작보다 끝이 뒤인지 확인합니다.
  • 전체 공개 요약을 보고 싶은 경우: 해당 요약 페이지를 확인합니다. 호환 시간표 파일에는 모든 근거 자료가 포함되지 않습니다.
