# 치지직 댓글로 만드는 Markdown 타임라인

다시보기 댓글에 **영상 경과시간과 설명**을 적으면 사람이 평문으로 읽고, 호환 도구가 같은 시각으로 이동할 수 있습니다. Markdown은 선택사항입니다. 계정 연동, 확장 설치, JSON이나 특정 서버를 알아야 작성할 수 있는 형식이 아닙니다.

이 저장소는 **현재 지원을 설명하는 공개 편집 초안 0.1**입니다. NAVER/CHZZK의 공식 표준이 아니며, 제품 전체 변환의 기본 출력이나 C08 수락을 확정하지 않습니다. 공개 문서 발행, 실제 댓글 게시, 확장 스토어 배포는 서로 다른 일입니다. 여기서는 댓글을 자동 게시하지 않습니다.

## 가장 작은 시작

```text
00:00 방송 시작
02:35 오늘 할 게임 이야기
08:12 다시 보고 싶은 순간
```

한 줄은 하나의 이동 지점입니다. `02:35`는 2분 35초, `1:02:35`는 1시간 2분 35초입니다. 방송 날짜나 벽시계 시각이 아닙니다. 제목 없이 `54:30`만 적어도 책갈피로 읽을 수 있습니다.

## 구간과 중요한 순간을 함께 쓰기

```text
# 00:00 ~ 20:00 인사와 준비
- 02:35 오늘 할 게임 이야기
- 08:12 ⭐ 다시 보고 싶은 순간
## 10:00 ~ 18:30 첫 번째 판
- 12:10 [메모] 앞 대화와 이어서 보기
# 20:00 ~ 30:00 다음 게임
합방: 가상 방송인 A, 가상 방송인 B
- 22:10 첫 사건
```

`#`와 `##`는 이야기 **구간**, `-`는 **한 순간**, `⭐`는 작성자가 강조한 표시입니다. `시작 ~ 끝`으로 범위를 직접 적으면 끝을 추측할 필요가 없습니다. 마지막 예제의 이름은 실제 방송인을 가리키지 않는 합성 이름입니다.

시작만 쓴 제목 구간도 읽을 수 있습니다. 다만 자동 끝은 다음 같은 단계/상위 제목, 부모 끝, 영상 길이와 본문 완전성을 확인해야 계산됩니다. 부분 본문이나 불명확한 경계에서는 끝을 모른다고 표시합니다. 플랫폼이 Markdown을 렌더링하지 않아도 위 댓글은 평문으로 읽을 수 있습니다.
