# CVA-탬패드 댓글 시간축 안내

다시보기 댓글의 **시각·목차·장면·관련 인물**을 읽고 확인하는 공개 문서입니다. 새 댓글은 간단한 시각 목록으로 시작할 수 있고, 기존 댓글은 원문을 보존하며 가져옵니다.

```text
00:00 방송 시작
02:35 오늘 할 게임 이야기
08:12 다시 보고 싶은 순간
```

한 줄은 하나의 이동 지점입니다. 시간은 영상 경과시간이며 날짜·벽시계 시각이 아닙니다. Markdown은 선택사항입니다.

## 현재 기준

공개 편집 초안 **0.4**, 소비자 **CVA-탬패드 0.3.23 후보**, 출력 식별자 `comment_preview.v2`입니다. 문서 버전·제품 버전·출력 schema는 서로 다릅니다. 공식 플랫폼 표준이나 모든 자연어 입력 지원을 뜻하지 않습니다.

새 호환 범위는 **명확한 상대 들여쓰기**, **단독 `■`로 나뉜 독립 목록**, **잘못된 시각의 정상 이웃 보존**입니다. `01:23 시작 (02:55)`의 괄호 시각은 원문과 확인 안내로 남기며 자동 이동 지점이나 종료로 확정하지 않습니다.

이 저장소에는 공개 설명·합성 예제·정적 사이트만 있습니다. 제품 parser 소스, 실제 사용자 댓글·계정 자료, 비공개 개발 이력을 배포하지 않습니다. 사이트는 온라인 parser나 자동 댓글 게시 서비스가 아닙니다.

## 재현

추가 라이브러리·인증 없이 Python 표준 라이브러리로 사이트를 만듭니다.

```text
python scripts/build_site.py
node scripts/validate.cjs
python -m http.server 8768 --directory docs
```

로컬 미리보기는 `http://127.0.0.1:8768/`에서 확인합니다. 이미 보유한 호환 parser를 선택적으로 대조하는 명령은 [검증 기록](VALIDATION.md)에 있습니다. builder는 parser를 다운로드하거나 공개하지 않습니다.

문서·합성 예제·사이트는 [MIT 라이선스](LICENSE)를 사용합니다. 차이는 개인정보를 제거한 최소 입력·기대 결과·실제 결과로 [기여](CONTRIBUTING.md)할 수 있습니다.
